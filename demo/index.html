About this demo

The widget is loaded with: 

<script
  src="../dist/leadbox.min.js"
  data-endpoint="https://demo.leadbox.invalid/api/leads"
  data-title="Get a Free Quote"
  data-subtitle="Tell us about your project and we'll follow up within one business day."
  data-button-text="Get a Free Quote"
  data-accent-color="#15803d"
  data-fields="name,phone,email,service,message,preferredContact"
  data-required-fields="name,phone"
  data-service-options="Lawn Care,Gutter Cleaning,Landscaping,Snow Removal,Other"
  data-booking-url="https://calendly.com/example/consult"
  data-phone="+19085551234"
></script>

Network requests are intercepted client-side (see demo/mock-endpoint.js) since GitHub Pages can only serve static files — in production you'd point data-endpoint at a real backend. See the README and docs/ for real backend options (Google Sheets, Formspree, Zapier/Make).
